# Security

Only the current 0.1.x series is supported. Report suspected vulnerabilities privately at
https://github.com/KanadeK/zip-name-audit/security/advisories/new . If private reporting is unavailable,
open a public issue requesting a private contact without including exploit details or sensitive data.

This tool performs local checks only. Its successful exit is limited to the documented checks;
it is not a guarantee that input data or a downstream application is safe. Review reports before sharing.
